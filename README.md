## 调研报告

**[Docs/Research.html](Docs/Research.html)**：单文件网页，下载后用浏览器打开。

Valve 没有发表这项技术的讲座或论文。报告的主要依据是 SteamDB 维护的 GameTracking-CS2 仓库（从每次发行版本自动导出的类结构、联网字段、控制台变量），以及用 Source 2 Viewer 从 SPIR-V 还原的着色器代码；社区复刻和一篇 2025 年的硕士论文作为补充。主要结论：

- 每颗烟是一个 32³ 的体素网格，每格 20 Hammer 单位（约 50 cm），16 颗烟共用一张 542×32×32 的三维图集。体素里存的是扩散的到达距离，所以生长、消散和挖空都在着色器里按时间计算，不需要改写体素。
- 子弹和高爆手雷都是带时间戳的事件，着色器按事件曲线临时挖空密度：子弹通道半径约 20 单位并在 1.6 秒内收拢，高爆把 200 单位内的烟清到 2%，0.5 到 5 秒内按曲线回填。
- 渲染是低分辨率光线步进加逐体素光照缓存，再按深度感知上采样，深度对不上的像素在全分辨率下补一次。
- 2024 年 10 月起，服务器把填充结果作为联网字段下发，各端不再各自填充。烟后的敌人位置不发给看不见的客户端，用来对抗透视外挂。

## UE 5.8 可交互 Demo

一个第一人称的小型突破关卡：庭院、带门和铁栅窗的长走廊、中路和包点。三名哨兵守着走廊、中路和包点拱门，玩家用烟雾弹封住他们的视线，用高爆手雷清开烟，推进到 A 点长按 E 安放炸弹。

“原理面板”（Tab，鼠标点选）按“扩散规则 / 交互 / 渲染 / 网络同步 / 公平性”五组列出开关。单选圆点表示互斥，方框表示逐层叠加，缩进的子项只在父项打开时生效；每一项标明“服务器”（所有玩家都受影响）或“本机”（只改这台机器的画面）。右上角实时显示各渲染阶段的 GPU 耗时、每颗烟的联网字节数和与服务器不一致的烟雾数量。

### 运行

| 脚本 | 作用 |
|---|---|
| `Run.bat` | 以主机（监听服务器）启动，单人游玩也用它 |
| `Run2P.bat` | 在同一台机器上左右并排开主机和客户端，对比两端画面。使用专用端口 17792，启动前先关闭之前打开的演示窗口，窗口标题标明主机 / 客户端 |
| `RunClient.bat [地址]` | 作为客户端加入另一台机器上的主机，默认 127.0.0.1；主机还没开时每 3 秒自动重试 |

需要 UE 5.8。脚本会自动查找引擎（见 `Tools/find_ue.ps1`），也可以用环境变量 `UE_ROOT` 指定引擎目录。首次运行前编译一次：

```
<引擎目录>\Engine\Build\BatchFiles\Build.bat VolumetricSmokeEditor Win64 Development -Project="<路径>\VolumetricSmoke.uproject"
```

### 实现要点

- **关卡体素化**：开局时用自定义碰撞通道 Smoke 对整张地图做 50 cm 体素的重叠检测，铁栅等带 `SmokePass` 标签的物体记为“烟可穿过”。门开关后只重建门附近的体素，并让碰到门的烟重新填充。
- **扩散**：三种规则写在 `SLVoxel.cpp`。体积守恒规则是 26 邻域的整数倒角 Dijkstra（竖直方向按椭球比例加权，禁止斜穿墙角），按距离由近及远填满固定体积；结果按每格一个字节存到达距离。
- **联网**：服务器填充后用 zlib 压缩下发（约 600 字节一颗）；“只发输入”模式只发起爆点和规则（24 字节）。子弹和爆炸事件是带时间戳的复制数组，自己的子弹在本地先预测。
- **渲染**：`SLRender.cpp` 中的场景视图扩展在后处理前用 RDG 插入三个通道：逐体素光照缓存（太阳自阴影、关卡遮挡、天空可见度、最多 6 盏点光）、低分辨率光线步进、深度感知上采样加全分辨率补洞，最后预乘混合进场景颜色。GPU 耗时用时间戳查询逐通道测量。
- **玩法与画面分离**：哨兵视线在 CPU 上沿线积分无噪声的密度（含子弹和爆炸挖空），超过 250 cm 即看不见；噪声只削弱边缘带，所以各端、各档画质看到的遮挡一致。

### 自测

`Tools/iterate.ps1 [-Assets] [-Net]` 编译工程、按需重建材质和地图，然后在屏幕外运行脚本化的自测：注入按键和鼠标输入、截图，并把结果写到 `Saved/Capture/*_results.txt`。`-Net` 会在 127.0.0.1 上再开一对主机和客户端，从客户端检查同步。最近一次的结果见 [Docs/host_results.txt](Docs/host_results.txt) 和 [Docs/client_results.txt](Docs/client_results.txt)，在 RTX 3060、1600×900 下：

- 1/4 分辨率加噪声纹理的步进约 0.5 ms，全分辨率加程序化噪声约 7–8 ms；整帧约 9 ms。
- 一颗烟填充 955 个体素，用时 0.3–0.7 ms；服务器下发 634 字节。
- 一发子弹从枪口射出后，弹道上的烟从 920 cm 降到约 80 cm；高爆后爆点密度 0.02，5 秒后回到 1.00。

## 素材

- 墙面、地面贴图与道具模型来自 [Poly Haven](https://polyhaven.com/)（CC0）。
- 角色、动画与步枪来自 UE 第一人称 / 第三人称模板（Epic Games，按 Unreal Engine EULA 在 UE 项目中使用）。
- 音效来自 OpenGameArt 上的 CC0 素材，用 ffmpeg 剪成单发、做淡出后放在 `SourceAssets/audio`：
  - 步枪：[The Free Firearm Sound Library](https://opengameart.org/content/the-free-firearm-sound-library) 中 AR-15 的近距离录音（自己开枪，不做空间化）和中距离录音（其他人开枪，带回声，3D 衰减）。
  - 高爆手雷：[25 CC0 bang / firework SFX](https://opengameart.org/content/25-cc0-bang-firework-sfx) 中的 `cannon_02`。
  - 烟雾弹起爆：同一包中的短爆 `shot_03`，叠加 [Steam release sounds](https://opengameart.org/content/steam-release-sounds) 中的泄压声。
